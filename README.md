# extras.simlearn

Stand-alone classroom tools for SimLearn, served by GitHub Pages at <https://extras.simlearn.online>.

- One folder per tool, each with its own `index.html` (e.g. `tariff-debate/` → `extras.simlearn.online/tariff-debate/`).
- Plain static HTML: no build step, no login, no cookies, no external requests. Fonts are self-hosted in `fonts/` (SIL Open Font License).
- Progress is kept only in the student's own browser (`localStorage`).
- Unless a tool says otherwise, authors, studies and figures are fictional, written for class. Confidence Bets and Beauty Bets use real, sourced figures (each answer cites its source); the creators and posts in Beauty Bets are invented.
- Add a link to each new tool in `index.html`.
